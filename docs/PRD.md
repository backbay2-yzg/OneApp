# OneApp 产品需求文档（PRD）

> **文档状态**：待审阅确认（Draft v1.0）
> **目标平台**：Windows 10 / Windows 11 优先（架构保留跨平台扩展能力）
> **核心技术栈**：Wails v3（Go 1.24 + React / TypeScript / Tailwind CSS）

---

## 1. 产品定位与目标边界

### 1.1 一句话定位

**OneApp** 是一款面向自研工具与免安装绿色软件的**「个人软件库 + 极速启动器 + 轻量级包与更新管理器」**。

### 1.2 核心痛点与产品价值

开发者和重度桌面用户手里通常积累了大量免安装软件（散落的自研小工具、各类单文件 `.exe`、绿色版压缩包、辅助脚本以及 GitHub Release 工具）。OneApp 解决以下四大痛点：

1. **收纳混乱**：绿色软件散落在桌面、下载目录、各个盘符深处，需要集中托管但又要兼容“正在开发的编译产物目录”。
2. **启动低效**：平时找工具得翻文件夹或记路径；希望能像 Raycast/uTools 一样快捷键秒弹，且对中文拼音、个人别名和工具用法友好。
3. **自研工具易忘**：自己半年前写的工具过久了会忘掉命令行参数或适用场景；一个软件套包可能包含多个可执行入口。
4. **线上获取与升级痛点**：从 GitHub 下载要手动在一堆资产里挑 Windows 便携包，下次升级覆盖解压又极易把本地 `config.json` / `data/` 冲掉。

### 1.3 明确的能力边界（Scope）

| 维度 | 纳入范围（In-Scope） | 刻意不做（Out-of-Scope） |
| :--- | :--- | :--- |
| **管理对象** | OneApp 托管库或显式链接的免安装软件（单 `.exe`、绿色整包目录、`.zip`/`.7z`、`.bat`/`.cmd`/`.ps1`/`.lnk`） | 不扫描 Windows 注册表/开始菜单已安装软件；不管理 `.msi` / 安装向导式重型应用 |
| **启动器范围** | 仅搜索 OneApp 管理的软件库；提供模糊/拼音/别名/标签搜索、`Tab` 二级动作、运行状态识别与单软件热键 | 不做全盘文件搜索、剪贴板历史、计算器、汇率/翻译、第三方插件生态市场 |
| **存储与迁移** | 混合存储（默认托管入库 + 可选仅链接原路径）；自身绿色便携；轻量 `oneapp-manifest.json` 导出与换机重拉 | 不自建云端账号系统或远程存储同步服务（可用网盘/Syncthing 直接同步整个便携目录） |
| **线上拉取与更新** | GitHub 仓库/Release 链接（含私有库 Token 与代理）与通用直链；资产智能匹配；配置零丢失升级与一键回滚 | 不自动注入系统 `PATH` shim；不提供社区软件源聚合商店 |

## 2. 双模式产品形态与交互设计

OneApp 采用**「双窗口 + 系统托盘常驻」**的混合交互形态：平时以极低资源占驻留托盘，高频启动走极速启动条，整理收纳、配置运行参数与更新管理走完整主窗口。

### 2.1 极速启动条（Launcher Window）

#### 窗口与唤醒行为
- **常驻预热**：OneApp 启动后即创建无边框、居中、置顶的启动条窗口并保持隐藏态，避免按下热键时的 WebView 冷启动卡顿。
- **全局热键唤出**：默认 `Alt + Space`（支持在设置中自由改绑；若与其他软件热键冲突需明确提示）。
- **无感收起**：按下 `Esc`、执行默认启动动作（可配置保持展开）或窗口失去焦点（带短防抖避免误触）后自动隐藏。
- **空状态智能推荐**：搜索框为空时，展示「最近使用 / 收藏置顶 / 正在运行」的高频快捷列表，不需打字即可上下方向键回车秒开。

#### 界面线框示意（Raycast / Linear 风格）

```text
+-----------------------------------------------------------------------+
|  >  jietu                                                [⌘K] 全部应用 |
+------------------------------------+----------------------------------+
| [图标] 截图标注工具 v1.4   ● 运行中  |  截图标注工具 (自研)              |
|        别名: jt / snip    #效率     |  版本: v1.4.2   模式: 托管库       |
|                                    |  ------------------------------  |
| [图标] Snipaste Portable   v2.8    |  个人笔记：                       |
|        标签: #截图                 |  - F1 快速截屏，F3 贴图           |
|                                    |  - 配置保存在 config.ini          |
| [图标] 屏幕取色器           v1.0    |  可用入口: 主程序 / 静默截图模式   |
+------------------------------------+----------------------------------+
|  ↵ 启动   Ctrl+↵ 管理员运行   Tab 更多动作   Esc 隐藏                   |
+-----------------------------------------------------------------------+
```
*(右侧预览面板支持开关折叠，默认展示选中项的版本、标签、可用入口及个人使用笔记摘要。)*

#### 搜索与匹配规则
1. **多维度匹配**：
   - 软件名称、英文子串与字符序模糊匹配（Fuzzy Match）
   - 中文全拼（如 `jietu` → `截图工具`）与拼音首字母（如 `jt` → `截图工具`）
   - 自定义别名（如为工具设置 `so`、`clip` 等高频短别名）
   - 标签过滤语法：`#标签名`（如 `#网络`）
   - 分类过滤语法：`@分类名`（如 `@自研`）
   - 状态过滤语法：`:running`（仅看运行中）、`:update`（有更新）
2. **Frecency 排序权重模型**：
   综合考量：**文本匹配分（前缀/全匹配加权） + 最近使用时间衰减（Recency） + 历史使用频次（Frequency） + 收藏加权**。对于新入库但尚未启动过的软件提供短期冷启动加权，避免新工具搜不到。

#### `Tab` 二级动作面板
选中任意软件按 `Tab`（或点击右键）切换为针对该软件的动作列表：
- **启动默认入口**（`Enter`）
- **启动辅助子入口**（若该软件配置了多个入口，直接在此列出）
- **以管理员身份运行**（`Ctrl + Enter`，通过系统 UAC 按需提权）
- **带临时参数运行**（弹出单行参数输入框，本次追加参数运行而不改永久配置）
- **打开所在目录**（调起资源管理器并高亮选中主程序）
- **在终端中打开目录**（在软件工作目录打开 PowerShell / Windows Terminal）
- **复制文件路径 / 复制启动命令**
- **结束进程 / 重启进程**（仅当该软件当前处于运行状态时出现）
- **查看完整笔记 / 在主窗口编辑**
- **立即检查更新**（仅针对已绑定线上源的软件）

#### 单软件独立全局热键
在软件详情中可绑定全局快捷键（如 `Ctrl + Alt + 1`），按下后绕过启动条直接拉起该软件的指定入口。

### 2.2 管理主窗口（Main Window）

#### 视觉风格
- **Raycast / Linear 现代开发者工具风**：高信息密度、克制边框与层级分割、等宽字体展示版本号/路径/快捷键、深浅色主题跟随 Windows 系统并支持手动锁定、支持全程键盘方向键浏览。

#### 经典三栏布局示意


#### 核心区块能力
- **左侧导航栏**：智能视图（全部、收藏、正在运行实时徽章）、自定义分类树、标签过滤、下载与更新队列（角标提示待更新数量）、批量导入/清单迁移入口、系统设置入口。
- **中间列表/网格区**：
  - 支持**紧凑卡片网格**与**高密度详情列表**一键切换；
  - 支持多维度排序（名称、最近使用、使用次数、添加时间、可更新优先）；
  - 全工作区响应原生文件拖放，文件拖入窗口时呈现半透明高亮热区；
  - 统一“+ 添加”入口支持：粘贴 GitHub/直链、选择本地文件/目录、启动批量目录扫描向导。
- **右侧详情抽屉**（四个清晰分段）：
  1. **基础信息**：图标替换/重新提取、名称、别名（多值标签）、分类、标签、简介、托管状态与目录占用大小、独立全局热键绑定、使用次数与最近启动时间。
  2. **多入口与运行配置**：添加/编辑/排序/设为主入口；每个入口独立配置类型、相对路径、启动参数、工作目录、环境变量（KV）、隐藏控制台窗口开关、默认管理员权限开关。
  3. **个人使用笔记**：轻量 Markdown 编辑器与渲染预览，用于沉淀“自己写的工具到底怎么用、参数有哪些”。
  4. **来源、更新与保留规则**：绑定/修改 GitHub 或直链来源、资产匹配规则、Pre-release 开关、配置保留规则（`persist_rules` glob 列表）、检查更新与历史备份版本一键回滚。

## 3. 五大核心业务流程与功能规格

### 3.1 收纳、拖入与批量迁移

#### 支持的软件与文件形态
- **单可执行文件**：`.exe`
- **绿色整包目录**：包含主 `.exe`、依赖 `.dll`、资源文件夹及配置文件的完整文件夹
- **压缩包**：`.zip`、`.7z`（支持拖入后自动解压入库）
- **脚本与快捷方式**：`.bat`、`.cmd`、`.ps1`、`.lnk`

#### 智能解析与规范化
1. **单层嵌套根目录自动剥离**：解压 `.zip`/`.7z` 或拖入外层套壳目录时，若顶层仅包含唯一子目录且无其他文件，自动将内部文件上提一层，避免出现 `apps/tool-xxx/tool-v1.0/tool.exe` 的冗余层级。
2. **启发式主入口识别**：面对含多个 `.exe` 的整包或压缩包，自动扫描根目录及浅层目录进行打分：
   - **降权/忽略**：文件名匹配 `unins*`、`uninstall*`、`updater*`、`crash*`、`reporter*`、`vcredist*`、`dxsetup*`、`*service*`、`*helper*`。
   - **加权**：与目录/压缩包同名的 `.exe`、位于根目录的 `.exe`、带有 GUI 图标与完整 PE VersionInfo 的程序。
   - **多入口保留**：识别出高分主入口后，其余非辅助类的有效 `.exe`/脚本在入库确认卡片中可直接勾选一并收为“辅助子入口”。
3. **元数据自动提取**：自动读取 Windows PE VersionInfo（产品名、版本号、描述）及提取高分辨率程序图标缓存至本地（`data/icons/`）。

#### 拖入确认卡与混合存储模式
拖入目标后弹出紧凑确认卡，支持修改名称、入口并选择存储方式：
- **复制入托管库（默认）**：原目录保持不变，完整拷贝进 `library/apps/<slug>-<shortid>/`。
- **移动入托管库**：迁移进托管库并移除原位置散落目录。
- **仅链接原路径**：文件留在原地，OneApp 仅保存路径引用（专为**持续开发中的自研项目输出目录**或体积庞大的工具设计）。
- *（拖入 `.zip`/`.7z` 压缩包时默认直接解压入托管库，源压缩包留原地不动。）*
- 支持勾选「记住本次默认模式」或开启「静默入库」（拖入后跳过弹窗直接按默认规则入库并在右下角轻提示）。

#### 已有工具箱批量扫描导入向导
为帮助用户把原本散落存放在某个盘符/文件夹中的几十个绿色软件和自研工具一次性接入 OneApp：
- 选择目标母目录（如 `D:\GreenSoft\`）；
- 自动识别第一层独立子目录以及散落根目录的独立 `.exe`/脚本；
- 展示可勾选的预览清单（识别名、推荐主入口、版本号、文件大小）；
- 允许整体或逐项设置「复制入库 / 移动入库 / 就地链接」与默认分类，点击后后台队列异步入库并展示进度。

### 3.2 线上下载与 GitHub 接入

#### 支持链接类型
1. **GitHub 仓库链接**：`https://github.com/owner/repo`（自动查询 Latest Release）
2. **GitHub 指定 Release / Tag 链接**：`https://github.com/owner/repo/releases/tag/v1.0.0`
3. **GitHub Release 资产直链**：`.../releases/download/...`
4. **通用 HTTP/HTTPS 直链**：指向 `.zip`、`.7z`、`.exe` 的直接下载链接

#### Windows 资产智能打分规则
当解析 GitHub Release 资产列表时，自动执行以下筛选打分：
- **优先加分项**：文件名包含 `win`、`windows`、`win64`、`x64`、`amd64`、`x86_64`、`portable`、`green`；扩展名为 `.zip`、`.7z`、便携单文件 `.exe`。
- **强降权/排除项**：
  - 其他平台：`darwin`、`mac`、`macos`、`osx`、`linux`、`ubuntu`、`.dmg`、`.appimage`、`.deb`、`.rpm`
  - 非便携安装器：`.msi`、文件名含 `setup`、`installer`、`install`（除非明确带 `portable`）
  - 辅助校验/源码文件：`.sha256`、`.md5`、`.sig`、`.asc`、`Source code (zip/tar.gz)`
- **交互兜底与记忆**：
  - 若最高分资产明显唯一，在预览卡片自动预选并展示文件名与大小；
  - 若有多个高分相近候选（例如同时提供 `cli` 和 `gui` 版，或 `win-x64` 与 `win-arm64`），列出候选项供用户点选；
  - 用户确认后，自动沉淀为该软件的 `asset_pattern`（资产文件名匹配规则），供后续自动更新精准复用。

#### 下载任务、校验、认证与代理
- **传输控制**：流式下载、实时进度（进度条、速率、已下载/总大小）、支持取消并自动清理临时碎片；下载完成后自动进入解压与主入口识别流程入库。
- **完整性校验**：若 Release 提供 SHA256 Digest 或同名校验文件，自动完成哈希核对。
- **GitHub PAT（Personal Access Token）**：设置页支持可选填写个人 Token，带来两大能力：
  1. 拉取用户自己的**私有 GitHub 自研仓库** Release；
  2. 解除未认证每小时 60 次 API 限流（提升至 5000 次/小时）。
  *(Token 仅以系统本机加密形式保存，不参与清单导出。)*
- **代理与镜像**：支持配置 HTTP / SOCKS5 代理（支持跟随系统或手动指定），并支持配置可选下载镜像/加速前缀以应对国内网络波动。

### 3.3 版本检查、配置零丢失升级与一键回滚

#### 更新检查策略
- **GitHub 源**：比对远端 Release Tag / Asset ID / Asset Digest 与当前安装记录（按软件独立开关是否包含 Pre-release 预发布版）。
- **直链源**：通过 HTTP `HEAD` 比对 `ETag`、`Last-Modified` 与 `Content-Length`。
- **检查方式**：支持在“下载与更新中心”手动一键检查全部、单软件检查，以及可选启动时后台自动静默检查。

#### 配置零丢失双保险机制
免安装软件升级最致命的问题是新版压缩包覆盖掉用户数据或修改过的配置文件。OneApp 采用**「Install Manifest Diff + 用户保留规则」**双保险机制：

1. **Install Manifest Diff（安装清单差异保护，自动生效）**：
   - 软件首次解压入库或每次升级完成时，OneApp 会扫描软件根目录并生成一份原始文件指纹清单（记录每个相对路径及其 SHA256 哈希）。
   - 下次升级合并文件前，将“当前软件目录现状”与“上次安装指纹清单”进行三向比对：
     - **用户新增文件/目录**（原始清单里不存在，例如软件运行生成的 `data/`、`logs/`、`cache/`、`*.db`、`plugins/`）→ **全量保留**；
     - **被修改过的原始文件**（原始清单里有，但本地文件哈希已变化，例如用户改写了软件自带的 `config.ini` / `settings.json`）→ **自动判定为用户配置，默认保留旧版不覆盖**；
     - **未改动过的原始程序文件**（`.exe`、`.dll` 等哈希与原清单一致）→ **安全替换为新版文件**。
2. **显式保留规则（`persist_rules`，兜底增强）**：
   - 支持用户按软件手动配置 glob 规则（如 `config/**`、`*.sqlite`、`user.json`），命中规则的路径在升级时无条件保留旧版。

#### 升级执行与回滚流程
1. **运行占用检测**：升级前检测目标软件是否正在运行，若占用则提示用户一键终止进程后再继续，避免 Windows 文件锁导致升级半残。
2. **Staging 暂存合并**：新版本在 `data/cache/staging/` 解压与剥离单根目录，并按上述双保险规则把旧版的保留文件合并入新版暂存目录。
3. **备份与原子替换**：将当前旧版目录完整移至 `data/backups/<app_id>/<timestamp>_<old_version>/`（默认保留最近 2 个历史版本，可配置），随后将合并好的新版目录原子移动上线，并写入新版本与新 Install Manifest。
4. **一键回滚**：若新版不兼容或有严重 Bug，用户可在详情页点击「回滚到此版本」，OneApp 立即从备份目录恢复旧版（同步保留回滚期间新增数据或恢复当时快照，清晰提示用户确认）并回退元数据版本号。

### 3.4 运行引擎与进程状态感知

1. **多入口与脚本调度**：
   - `.exe`：直接执行目标程序，注入工作目录与环境变量。
   - `.bat` / `.cmd`：通过 `cmd.exe /c` 执行，支持隐藏控制台黑窗。
   - `.ps1`：通过 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File ...` 执行，支持隐藏控制台黑窗。
   - `.lnk`：解析目标路径、原参数与起始位置执行。
2. **参数模板与动态环境变量**：
   - 参数支持内置占位变量：`{{APP_DIR}}`（软件目录）、`{{ENTRY_DIR}}`（入口所在目录）、`{{ONEAPP_DIR}}`（OneApp 根目录）；
   - 支持配置启动前自定义环境变量（Key-Value 键值对）；
   - 支持开启“启动时询问附加参数”或通过启动条 `Tab` 传入单次临时参数。
3. **按需 UAC 提权（关键设计约束）**：
   - OneApp 主程序**永远以普通用户权限运行**（否则受 Windows UIPI 隔离限制，普通权限的 Windows 资源管理器将无法把文件拖入高权限窗口）；
   - 当软件入口配置为「以管理员身份运行」或用户在启动条按下 `Ctrl + Enter` 时，通过 Windows `runas` 动词单独对该子进程发起 UAC 提权启动。
4. **进程状态感知与管理**：
   - 记录由 OneApp 拉起进程的 PID 与可执行文件路径校验；
   - 实时轮询/监听进程存活状态，在主窗口和启动条上呈现绿色「运行中」圆点及托盘/侧边栏实时计数；
   - 支持一键安全结束进程或重启进程；精确记录使用次数（`launch_count`）和最近启动时间（`last_launched_at`）反哺搜索排序。

### 3.5 自身绿色便携与换机轻量清单

1. **自身绿色便携架构**：
   - OneApp 自身为免安装应用，默认开启便携模式，所有运行时数据（数据库、配置、图标缓存、备份）存储在程序同级的 `data/` 目录，默认托管库存储在同级 `library/` 目录。
   - **托管软件全程相对路径**：数据库中只存相对于托管库根目录的路径（如 `apps/my-tool-a1b2/tool.exe`）。因此用户把整个 `OneApp/` 目录拷到 U 盘、移动硬盘或放进 OneDrive/Syncthing 同步盘，在任何电脑任意盘符打开即可直接使用，全部路径零损坏。
   - *(仅当用户显式开启「仅链接原路径」模式时才记录外部绝对路径或环境变量路径。)*
2. **轻量清单导出与换机恢复（`oneapp-manifest.json`）**：
   - **导出内容**：软件名、别名、分类、标签、简介、托管模式标识、多入口相对路径与启动配置（参数/环境变量/UAC/隐藏黑窗）、个人使用笔记、GitHub/直链来源、资产匹配规则、`persist_rules`。
   - **安全红线**：**绝不导出 GitHub Token、本地敏感凭据或临时缓存**。
   - **新电脑导入恢复流**：
     - 读入 `oneapp-manifest.json` 后自动合并分类与标签；
     - **带有线上来源的软件**：进入批量恢复队列，点击「一键全部重装」即可自动从 GitHub/直链重新拉取安装，并完整保留原来的参数配置、个人笔记与保留规则；
     - **纯本地自研（无线上来源）的软件**：创建元数据占位卡片并标记为**「待补齐文件」**（保留好笔记、别名、入口参数设定），用户之后将 `.exe` 或目录直接拖到该待补齐条目上即可自动完成文件绑定，不丢失任何配置。

## 4. 核心用户场景端到端走查

### 场景 A：冷启动——将散落多年的自研工具与绿色软件一键收编
1. 用户解压绿色版 OneApp 并双击运行，主窗口提示可进行「批量导入已有软件」。
2. 用户选择自己常用的 `D:\MyTools` 目录，OneApp 自动扫描出 18 个工具子目录和 5 个单文件 `.exe`。
3. 用户把其中 2 个还在每天 `go build` 的自研项目勾为「仅链接原路径」，其余 21 个勾选「移动入托管库」并批量打上 `#自研` / `#工具` 标签，点击导入完成收编。

### 场景 B：日常工作流——快捷键秒搜与多动作控场
1. 写代码过程中需要用自己的端口扫描小工具，按下 `Alt + Space` 瞬弹极速启动条。
2. 敲入拼音首字母 `dk`，第一条就命中目标工具，右侧预览面板同时显示出半年前写好的参数笔记。
3. 用户按 `Tab` 展开动作菜单，选择「带临时参数运行」，输入 `-p 8000-9000` 并回车启动；用完后再次唤起启动条搜到该工具（带绿色运行中标志），`Tab` 一键结束进程。

### 场景 C：线上获取与“无痛”版本更新
1. 用户将某个开源工具（或自己的私有 GitHub 仓库）链接粘贴进 OneApp，设置好私有 Token 后，OneApp 自动匹配出 `*-win-x64-portable.zip` 并流式下载解压入库。
2. 两周后软件发布新版本，OneApp 在「下载与更新中心」提醒可更新。用户点击升级：工具内早已调好的 `config.json` 和产生的历史数据文件夹 `data/` 被双保险机制完整保留，老版本自动封存进 `backups/`。若发现新版有 Bug，点击一次回滚即秒回旧版。

### 场景 D：更换新电脑
- **做法一（整包拷贝）**：直接把放满工具的整个 `OneApp/` 文件夹拖进移动硬盘拷到新电脑，双击 `OneApp.exe`，所有托管软件、图标、配置、笔记原样复活。
- **做法二（轻量清单还原）**：只带一份几十 KB 的 `oneapp-manifest.json` 到新电脑导入，一键批量从 GitHub 重新拉取所有开源工具，同时按列表提示把几个纯本地自研 `.exe` 拖回对应占位卡片即可还原完整工作台。
